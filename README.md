# Snake (pygame)

A classic snake game built with Python and pygame (May 2023). I followed a GeeksforGeeks tutorial to learn how pygame handles windows, input and a game loop, so the window title still carries its name.

## How it plays

- Steer the snake with the arrow keys.
- Each fruit eaten adds 10 points and makes the snake longer.
- The game ends if the snake hits a wall or itself, and a screen shows your final score.

## Run it

```
pip install pygame
python "#snakegame-inpython.py"
```

## What I practiced

The pygame event loop, drawing and collision checks, and keeping track of game state.
